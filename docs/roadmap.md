# Q7 输入法开发路线图

渐进式开发：每个阶段可交付、可验收；**最大风险（TSF 打通、候选窗技术验证）前置到阶段 0**。

## 阶段 0 · PoC 打通（风险前置，最重要）

- **目标**：最小闭环——宿主应用按键 → TSF DLL → 管道 → Server → 指令回注 → 上屏"测试"二字。
- **交付物**：
  - `q7-tsf`（先 x64）注册后被系统识别为输入法（TIP 注册）
  - 命名管道 IPC 往返 + 协议 v0（阶段 0 冻结）
  - Tauri 候选窗原型：透明 + `WS_EX_NOACTIVATE` + 跟随光标 + 预创建预热
- **验收标准**：
  - 在记事本 / Chrome / VS Code 中均能上屏
  - 按键 → 候选显示 P95 < 30ms
  - 候选窗点击不抢宿主焦点
- **决策门**：WebView 候选窗若延迟/内存不达标 → 切 Skia/Direct2D 原生渲染（保持窗口抽象可替换）。

## 阶段 1 · MVP：可用的全拼输入法

- **引擎**：全拼、音节切分、词图 DAG、词频打分、多候选 / 翻页 / 数字选词。
- **词典**：`.q7dict` 编译管线（`data/dict-src` → `dict-build`）+ 开源词库接入（许可清晰的数据源）。
- **交互**：组字串、Backspace / Esc、中英切换、全/半角标点。
- **用户词库**：SQLite——自造词 + 频次记忆。
- **界面**：设置界面 v1（Tauri + Vue：候选数、基础外观）；托盘；NSIS 安装包 + 开机自启。
- **预留落实**：候选管线按 `CandidateProvider` trait 组织；`CandidateProvider trait + 内置实现` 即"未来的插件占位"。
- **验收标准**：
  - 日常办公可替代系统拼音一整天无明显阻断
  - 常驻内存 < 150MB（含 WebView2）
  - x86 DLL 就绪

## 阶段 2 · 体验完善 + 兼容性 + 正式发布

- **输入增强**：简拼、双拼（可配置）、模糊音、纠错、自定义短语。
- **稳定性**：DLL 全入口 `catch_unwind`；Server 掉线时 DLL 降级为英文直通并自动重连；72h 压测无泄漏。
- **兼容性矩阵**：Office / WPS、Chromium 系（Chrome/Edge/VS Code/Electron）、UWP、Windows Terminal、远程桌面、多屏 / DPI、深色模式。
- **发布**：Tauri updater 自动更新、卸载清理、代码签名、安全软件白名单指引。
- **验收标准**：兼容性矩阵通过率达标；输入延迟 P99 < 50ms。

## 阶段 3 · AI 能力

- **3a 本地**：n-gram 下词预测 → 小模型重排（智能整句候选置顶）。
- **3b 云端**：`AiProvider` 接入 OpenAI 兼容 API；润色 / 续写 / 翻译；AI 设置页（模型 / Key / 场景开关）；隐私策略全量落地（密码框等敏感场景零外发）。
- **验收标准**：断网 / 超时不影响基础输入；密码框场景可抓包验证零外发。

## 阶段 4 · 插件系统

- **4a 运行时**：wasmtime 宿主 + `plugin-api.wit` 接口 + 权限模型 + 沙箱验证用例。
- **4b 管理**：插件目录规范（`%APPDATA%\Q7\plugins\<id>`）、管理 UI（启停 / 配置 / 日志 / 热重载）、3 个官方示例插件（`:smile` 出 emoji、`riqi` 出日期、计算器）。
- **4c（可选）**：插件仓库索引 + 签名校验 + 分发。
- **验收标准**：示例插件全部工作；超时 / 恶意插件不影响打字（沙箱测试通过）。

## 阶段 5 · 长期

跨平台复用（macOS IMK / Linux fcitx5 只换壳，引擎核心不动）；词库云同步；皮肤社区。

## 贯穿性工作

- **CI**：GitHub Actions windows runner；构建矩阵 x64 / x86 / arm64；`clippy`；前端构建。
- **可观测**：`tracing` 日志（滚动文件）；崩溃上报（可选，注意隐私合规）。
- **签名**：开发者证书 / EV 证书，安装包与 DLL 全签名。
